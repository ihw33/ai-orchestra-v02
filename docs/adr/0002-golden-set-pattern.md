# ADR 0002: Golden Set 패턴 도입

- 상태: 제안됨
- 날짜: 2025-09-02
- 작성자: PM Claude

## 배경(문제/문맥)
- AI가 복잡한 작업 실패 시 PM이 샘플 코드를 작성하는 상황 발생
- PM이 코드를 작성하면 역할 경계 위반
- AI가 성공한 패턴을 재사용할 체계 부재

## 결정(Decision)
1. **Golden Set 시스템 도입**: 성공한 구현을 참조 패턴으로 저장
2. **단계적 가이드 제공**: 코드 없이 방향만 제시
3. **에스컬레이션 프로세스**: 실패 시 점진적으로 구체화

## 근거(Why)
- PM의 역할 경계 명확화 (관리자 vs 구현자)
- AI의 자율적 학습 능력 향상
- 성공 패턴의 재사용으로 효율성 증대

## 대안(Alternatives)
1. ❌ PM이 계속 샘플 제공 → 역할 경계 모호
2. ❌ AI 무한 재시도 → 비효율적
3. ✅ Golden Set + 에스컬레이션 → 균형적 접근

## 결과(Consequences)
### 긍정적
- PM 역할 경계 명확화
- AI 자율성 향상
- 패턴 재사용으로 품질 일관성

### 부정적
- 초기 Golden Set 구축 필요
- 에스컬레이션 프로세스 복잡도
