## 🎯 핵심 통합 포인트

### 1. KB → LLM 데이터 흐름
```yaml
Knowledge Retrieval:
  - 사용자 쿼리 → KB 벡터 검색
  - Top-K 관련 문서 추출
  - 컨텍스트 구성 (최대 토큰 제한 고려)
  - LLM Service로 전달

Context Enhancement:
  - 검색된 문서 + 메타데이터
  - 시맨틱 관련성 점수
  - 시간적 관련성 (최신성)
  - 사용자 히스토리
```

### 2. LLM → KB 피드백 루프
```yaml
Knowledge Update:
  - LLM 생성 콘텐츠 → KB 저장
  - 자동 임베딩 생성
  - 카테고리 자동 분류
  - 품질 점수 계산

Learning Loop:
  - 사용자 피드백 수집
  - 답변 품질 평가
  - KB 가중치 업데이트
  - 검색 알고리즘 최적화
```

### 3. 실시간 동기화
```yaml
Real-time Sync:
  - WebSocket 연결 (Main ↔ KB ↔ LLM)
  - 이벤트 기반 업데이트
  - 캐시 무효화 전파
  - 상태 동기화

Performance Optimization:
  - Redis 공유 캐시
  - 배치 처리 큐
  - 비동기 파이프라인
  - 로드 밸런싱
```
